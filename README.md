# 📖 Overview

CalmWave Connect is an AI-powered mental wellness platform designed to provide accessible, secure, and personalized emotional support. The platform combines conversational AI, mood analytics, and private journaling to help users better understand and improve their mental well-being.

---

# ✨ Key Features

- 🤖 AI-powered Mental Health Assistant
- 📊 Daily Mood Tracking & Analytics
- 📖 Secure Personal Journal
- 🔐 User Authentication
- ☁️ Cloud Database with Supabase
- 📱 Fully Responsive Design
- 🌙 Modern & Minimal UI
- 📈 Wellness Progress Dashboard

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/SUCHNA24/calmwave-connect-36.git
```

Go to the project folder

```bash
cd calmwave-connect-36
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
